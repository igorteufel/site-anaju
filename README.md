# Story que Vende — Ana Julia

Landing page de vendas do produto digital **Story que Vende**, construída em
React, Vite, styled-components e Framer Motion.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

O resultado de produção é gerado em `dist/` e o projeto inclui configuração de
rotas para publicação na Vercel.

## Estrutura principal

- `src/App.jsx`: conteúdo, navegação, interações e seções da landing page;
- `src/styles/site.js`: composição responsiva e estilos dos componentes;
- `src/styles/theme.js`: tokens de cor, tipografia, layout e sombras;
- `public/assets`: fotografias e exemplos reais do produto;
- `design-reference`: direção visual aprovada;
- `design-qa.md`: relatório de validação visual e funcional.

Os botões de compra direcionam para a página oficial do produto na Hotmart.
